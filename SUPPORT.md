# Support

Fulcrum Boundary is an open-source, maintainer-supported project. Support is
best effort and does not include a guaranteed response window or hosted
incident-response service.

## Start here

- Installation and first run: [docs/INSTALL.md](./docs/INSTALL.md)
- Govern an MCP server: [docs/GOVERN_MCP_SERVER.md](./docs/GOVERN_MCP_SERVER.md)
- Troubleshooting: [docs/TROUBLESHOOTING.md](./docs/TROUBLESHOOTING.md)
- Current limits: [LIMITATIONS.md](./LIMITATIONS.md)
- Full documentation: <https://fulcrum-governance.github.io/Fulcrum-Boundary/>

## Ask a question

Use the [Q&A category in GitHub Discussions](https://github.com/Fulcrum-Governance/Fulcrum-Boundary/discussions/categories/q-a)
for setup help, usage questions, and design discussion. Include the Boundary
version, operating system, installation method, and the command or route you
are trying to use.

## Report a bug or request a feature

Use the repository's issue forms. Bug reports should include a minimal
reproducer and the observed decision or error. Larger feature proposals should
start with the concrete routed-action problem rather than a broad platform
request.

## Report a vulnerability

Do not open a public issue. Follow [SECURITY.md](./SECURITY.md) and use the
private reporting path documented there.
